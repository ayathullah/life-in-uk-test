# Life in the UK Practice Portal

A free static practice site for GitHub Pages.

## Publish
1. Create a **public** GitHub repository (for example `life-in-uk-test`).
2. Upload `index.html` to the repository root and commit it.
3. Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Visit the GitHub Pages address displayed in Settings → Pages.

## Features
24-question timed mock exams, topic revision, explanations, mistakes review, history and device-local progress. No login or server.

## Important
This is an independent starter prototype with **24 original illustrative questions**, not 1,000. Questions are not certified official exam questions. Expand and review the bank against the current official handbook before relying on it for study. The 75% threshold and 45-minute mock format reflect the usual Life in the UK test format.

## Privacy
History is stored only in browser localStorage; it does not sync between devices and can be lost if browser data is cleared.
